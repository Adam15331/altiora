# Altiora

Free, client-side university course finder: <https://usealtiora.com>.
Static HTML/CSS/JS served by GitHub Pages — **there is no build step**; the
site is the files in this repo.

## Development

```
npm install      # dev tooling only (ESLint, TypeScript) — not needed to run the site
npm run check    # lint + typecheck + validate requirements data + tests (CI runs this)
```

- Admissions requirements (per course, per admissions cycle): `data/requirements/` —
  schema, checks and the annual update process in [`docs/requirements-data.md`](docs/requirements-data.md).
- Unverified / partly verified requirements awaiting review: [`docs/requirements-review.md`](docs/requirements-review.md)
  (generated by `npm run report`).
- Field guide pages (`fields/*.html`) are generated by `node scripts/build-field-pages.mjs`.
- Entry-requirements pages (`courses/*.html`, `universities/*.html`) are generated by
  `node scripts/build-course-pages.mjs` from the course data and the current cycle file. Each
  embeds the app's own Entry requirements panel, so a page never says more than a course card.
  `npm run build-pages` runs both generators; CI also regenerates them on every push to `main`.
